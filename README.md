# Python-Exercicios-Basicos
Nesta lista de exercícios, explorei a implementação de estruturas condicionais e a conversão de tipos de variáveis (input do teclado). O processo foi essencial para entender como o Python processa diferentes dados e como depurar erros durante a escrita do código

Durante o desenvolvimento destes exercícios, apliquei conceitos fundamentais de lógica de programação, com foco em estruturas condicionais (if, elif, else). Além disso, pude compreender a importância da tipagem de dados ao manipular entradas do usuário e aprimorar a capacidade de identificação e correção de erros comuns de sintaxe e lógica."
